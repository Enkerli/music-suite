Actions & controls

badge badge up

Controls use --es-border-strong (≥3:1); panels keep the decorative border. The select wears an ink chevron (theme-aware) instead of OS chrome. Tab through to see the focus ring.

The shared frame (one cluster, one Library — same slots in all ten apps)

The live cluster is in this page's header ↑ — theme · MIDI · density · Library, in that order, always top-right (or rail-header). Stable ids: #theme-toggle #midi-chip #density-toggle #library-toggle. The theme label names the target mode; the MIDI chip's LED always rides with a word; density toggles .es-dense on the whole page; Library opens the one save/recall drawer. Apps without MIDI simply omit slot 2 — nothing reflows.

the saved-item card — one treatment, three kinds

name · meta · source · kind badge · recall on tap · delete. Kinds map 1:1 onto @enkerli/library: document (wrapProgression/wrapClip), patch (wrapPatch), profile (wrapCurationProfile). Delete is the two-tap inline idiom — tap ✕, it arms (Delete?, pulsing), tap again commits; blur or 3 s disarms. Never a modal (window.confirm is a silent no-op in WKWebView).

Output range (dual-thumb, elastic edge, draggable band — the DrawnQurve/PitchFold control)

Drag a thumb (rubber-bands past either end), drag the band to slide the whole range, or shove it into a wall to compress. 44px touch targets, larger on coarse pointers. Keyboard: ←/→, Shift for an octave, Home/End.

Transport & arming (state word never colour-only; motion doubles the cue)

idle

Armed pulses danger-red; playing pulses the accent. Both spell out the state (idle / armed / playing / recording). Pulsing is suppressed under prefers-reduced-motion.

PCS Pads

Eight pads and a centre button, the way an Orba or a Lightpad would select pitch-class sets.

Instrument

1–8 pads · C or Space centre (hold it, then a pad, to change mode) · Esc cancel cue · Enter start/stop. In Octal, type the digits 0–7 (C Ionian is 5 6 2 5); the outlined pad keeps the current set.

Set

Up next:

Click a note on the ring to add or remove it; Shift-click a member to make it the root.

When changes apply

Loop = four bars of 4/4. A cue waits for its boundary; a coarser boundary also counts (a loop is a bar is a beat).

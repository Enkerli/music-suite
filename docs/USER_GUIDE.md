# User guide → it lives on the site

The suite's plain-language user guide is a **site page**, single-sourced in
[`site.md`](site.md) like all site copy (standing rule):

- **Read it:** <https://enkerli.github.io/music-suite/doc.html?p=suite-guide>
- **Edit it:** the `<!-- page suite-guide -->` block in [`site.md`](site.md),
  then `npm run build-site`.
- The generated in-repo copy is [`content/suite-guide.md`](content/suite-guide.md);
  screenshots live in `assets/guide/` (captured 2026-07-20, light theme).
- The ProgGenie-specific walkthrough is its own page:
  `doc.html?p=user-guide`.
